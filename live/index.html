เชื่อมต่อเพื่อดูงานจริงบนคอมพิวเตอร์นี้

ครั้งแรก? เริ่มได้ใน 3 ขั้นตอน

  1. ดาวน์โหลด Kubo สำหรับ WindowsWindows x64 · พร้อมใช้งาน ไม่ต้องติดตั้งโปรแกรมเพิ่ม
  2. คลิกขวาที่ไฟล์ ZIP → Extract All (แยกทั้งหมด)
  3. ดับเบิลคลิก Start Kubo ห้องเรียนจะเปิดพร้อมเชื่อมต่อให้เอง

เปิด Start Kubo ไว้แล้ว? เข้าห้องเรียนได้เลย:

เปิดห้องเรียนที่เชื่อมต่อแล้ว →

ห้องเรียนแบบเชื่อมต่อทำงานในเครื่องคุณเท่านั้น ครั้งต่อไปเปิด Start Kubo ได้เลย ไฟล์นี้สำหรับ Windows ส่วนเครื่องอื่นยังเรียนผ่านเว็บได้

แสดงเฉพาะงานในเครื่องคุณ ผู้เข้าชมคนอื่นไม่เห็นงานเหล่านี้

การเชื่อมต่อทำงานอย่างไร

ใช้งาน Codex หรือ Claude Code ตามปกติ Kubo แสดงเฉพาะสถานะงานในเครื่อง ไม่แสดงพรอมป์ต์ คำตอบ หรือผลลัพธ์คำสั่ง และไม่เปิดแอป AI หรือส่งกิจกรรมไปที่ Vercel
